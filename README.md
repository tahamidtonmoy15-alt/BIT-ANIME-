# BitAnime — Android APK

Premium anime catalogue and offline video vault packaged as an Android app.

## Build APK

Every push to `main` runs GitHub Actions. Open **Actions → Build BitAnime APK** and download the `BitAnime-debug-apk` artifact, or use the APK attached to the automatically-created GitHub Release.

The app uses Android WebView with a secure local asset origin, JavaScript, DOM storage, IndexedDB, and Android document picker support for video uploads.
